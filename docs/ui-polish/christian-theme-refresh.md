# Tema visual cristiano

## Dirección

Se aplicó un tema cristiano juvenil y sobrio a la aplicación:

- Fondo oscuro cálido con acentos dorado, oliva y esmeralda.
- Luz ambiental tipo comunidad/adoración.
- Patrón geométrico sutil de cruz en ventanas privadas.
- Textura suave tipo vidriera sin usar imágenes externas.
- Cards con borde luminoso, profundidad y tonos pastorales.
- Botones y tabs con acento dorado cálido.

## Alcance

El cambio se implementó principalmente en el sistema visual compartido:

- `app-page`
- `app-card`
- `app-card-soft`
- `app-card-accent`
- `app-hero-panel`
- `app-kicker`
- `app-chip`
- `app-button-primary`
- nueva clase `faith-page`

También se aplicó a:

- Pantallas de entrar, crear cuenta, recuperar y actualizar contraseña.
- Demo pública.
- AppShell privado.
- Header/Layout/PageHeader públicos.

## Criterios

- No se agregaron módulos nuevos.
- No se tocó Auth/RLS.
- No se tocó Biblia corpus.
- No se tocó Gemini ni secretos.
- Se mantuvo la app en español.
- Se evitó un diseño institucional; la intención sigue siendo red social cristiana/PWA juvenil.
